# «Новый день» — две концепции главной страницы

Пансионат для пожилых, Челябинск, ул. Чичерина, 21Б. Статичные HTML + CSS, без JS и сборки.

```
novy-den-site/
├── index.html   переход к выбранной концепции
├── img/          фото-заглушки (общие для обеих концепций)
├── concept-1/    «Светлая и простая»: index.html + styles.css
└── concept-2/    «Ответы родным»:     index.html + styles.css
```

Открыть: `index.html`, `concept-1/index.html` или `concept-2/index.html` в браузере. Картинки подключены как `../img/…`.

Для локальной проверки: `python3 -m http.server 8765 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8765/`.

## Презентационные изображения

В обеих концепциях используется один новый набор из шести ИИ-фотографий `img/*-v2.jpg`: общение с сотрудницей, комната, гостиная, столовая, ванная, обед. Сгенерированы встроенным `image_gen` 24 октября 2026 года. Это вымышленные иллюстрации, а не фотографии пансионата; предупреждение размещено на обеих страницах. Исходные `img/*.jpg` без суффикса `-v2` сохранены и больше не подключены.

`img/logo-placeholder.png` — временный знак «дом и восходящее солнце», с прозрачным фоном, общий для обеих концепций. Промты и назначение файлов — в `img/generation-prompts.json`.

## Концепции

| | Концепция 1 | Концепция 2 |
|---|---|---|
| Шрифты (Google Fonts) | Nunito | Lora (заголовки) + Golos Text |
| Акцент | `#2F6690`, скруглённые кнопки | `#1F3A52`, радиус 8 px |
| Структура | шапка → первый экран → 4 преимущества → услуги → фото → цены (карточки) → 3 шага → отзывы → FAQ → контакты | полоса контактов → шапка → первый экран по центру → 5 «вопросов родных» зигзагом → цены (таблица) → отзывы → экскурсия → контакты |

Цвета и радиусы — переменные в `:root` в начале каждого `styles.css`.

## Требования клиента (из брифа) — не нарушать

- Главная кнопка — **«Позвонить»**. Запись на экскурсию — только звонок или сообщение (Telegram, MAX), **без формы записи**. Допустима только форма обратного звонка (один телефон).
- **Не упоминать** медицинскую лицензию, ЛФК, лечение и сложные медицинские услуги. Про лекарства — только «контроль приёма лекарств по назначению врача».
- Цвета: белый, голубой, серый. Без ярких цветов, мелкого текста, сложного меню, всплывающих окон.
- Территории у пансионата нет — не показывать.
- Цены по состоянию человека: самостоятельные 1 700 ₽, нуждающиеся в помощи 1 900 ₽, маломобильные 2 000 ₽.

## Что заменить перед запуском

- `img/*` — **сгенерированы ИИ, это заглушки.** Клиент обещает реальные фото — они главный фактор доверия. Фото проживающих — только с их согласия (вопрос не решён).
- `[телефон]` и `tel:+70000000000` — номер клиента ещё не окончательный (клиент меняет SIM).
- Ссылки `href="#"`: Telegram, MAX, Яндекс Карты, 2ГИС, «все фото», политика ПДн.
- `.map-slot` — вставить виджет Яндекс Карт.
- `[в квадратных скобках]` — данные, которых нет в брифе: что оплачивается отдельно, меню, тип комнат, расписание питания, названия остановок, отзывы.
- Логотип: `.logo__mark` — временный сгенерированный знак. Перед запуском согласовать или заменить.
- Форма обратного звонка не подключена: поле и кнопка отключены, рядом есть пояснение. Телефон не передаётся через GET-запрос. Подключать только отдельной задачей.

## Исправления адаптивности

- Главное фото сохраняет заданные CSS-пропорции вместо фиксированной высоты HTML.
- Мобильные контейнеры меняют только горизонтальные отступы; вертикальные отступы разделов сохраняются.
- Во второй концепции таблица цен на мобильных отображается карточками, все описания и суммы доступны без горизонтальной прокрутки. В HTML сохранены роли таблицы и заголовков.
- Блоки ответов на мобильных имеют естественную высоту; текст не растягивается до 420 px.
- Тексты о лекарствах приведены к формулировке клиента. Плейсхолдеры комнат, расписания питания и остановок присутствуют в обеих концепциях.
- Размер текста — не менее 18 px; добавлен видимый клавиатурный фокус и учтено уменьшение движения.

## Публикация

Статический проект, без сборки и зависимостей. GitHub Pages публикует корень ветки `codex/novy-den-site`; файл `.nojekyll` отключает обработку Jekyll. Клиент выбрал `concept-1`; корневая страница перенаправляет на неё. `concept-2` сохранена по прежнему адресу для сравнения. Во всех трёх HTML стоит `noindex, nofollow`, поскольку это презентация с плейсхолдерами.

В выбранной концепции после тарифов размещена акция к открытию: при оплате сразу за 1, 2 или 3 месяца — соответственно 3, 5 или 7 дней бесплатно. Срок действия и дополнительные условия не указаны; подробности предлагается уточнить по телефону.

## Допущения, которые стоит подтвердить

- Цены указаны **«в сутки»** — в брифе единица не названа.
- Описания трёх ценовых категорий сформулированы по смыслу, клиент их не давал.
